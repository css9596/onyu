## 콘텐츠 등급

### Apple
- **17세 이상**? **12+**?
- 사주는 일반적으로 12+ 적정. "Frequent/Intense Mature/Suggestive Themes" 항목 No.
- 단, "Frequent/Intense Horror/Fear Themes" — 죽음 관련 사주 풀이 가능성 → 점진적 노출 → "Infrequent/Mild" 추천

- 설문에서 "운세, 점성술, 점" 카테고리에 해당
- 결과적으로 보통 **만 3세 이상** 또는 **만 12세 이상**으로 분류
